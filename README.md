# หนังสือเรียนภาษามลายู อก.3 · Buku Teks Bahasa Melayu Tahun 3

เว็บไซต์หนังสือเรียนภาษามลายู ชั้นปีที่ 3 หลักสูตรอิสลามศึกษาตอนกลาง (อก.3) · Kurikulum Pendidikan Islam Peringkat Pertengahan
เนื้อหาตรงกับหนังสือเล่ม (ไฟล์ Word `BukuTeks_BM_AK3.docx`) ใช้ภาษามลายูมาตรฐานทั้งหมด

เรียบเรียงโดย ผศ.มูหำหมัด สาแลบิง · สาขาวิชาภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ

ที่อยู่เว็บไซต์: https://salaebing-bahasa.github.io/buku-bm-ak3/

## มีอะไรในเว็บไซต์

- บทเรียน 6 บท (`pelajaran/01.html` เป็นต้นไป): สุนทรพจน์ (ชนิดของประโยค) · ผังความคิดจากบทความ · ข่าว: องค์ประกอบและโครงสร้าง · คำพูดตรง คำพูดอ้อม และการอ่านข่าว · แผนภูมิ กราฟ และอินโฟกราฟิก · เรื่องสั้นสุภาษิตและโครงสร้างประโยคพื้นฐาน
- ทุกจุดแสดงสองภาษา ภาษามลายูบรรทัดบน ภาษาไทยบรรทัดล่าง
- ปุ่มฟังเสียงคำศัพท์ บทสนทนา และเรื่องอ่าน (ใช้ระบบอ่านออกเสียงของเครื่อง)
- แบบฝึกหัดพร้อมปุ่ม “ดูเฉลย” แบบทดสอบตนเอง และบัตรคำท้ายบท
- อภิธานศัพท์พร้อมช่องค้นหา (`glosari.html`) และบรรณานุกรม APA ฉบับที่ 7 (`rujukan.html`)
- ปุ่ม "Muat turun PDF / ดาวน์โหลด PDF" ในแต่ละบท (ไฟล์อยู่ในโฟลเดอร์ `pdf/`)

## วิธีแก้ไขเนื้อหา

เนื้อหาทั้งหมดอยู่ในไฟล์ `_src/data/ak3.js` ไฟล์เดียว
ข้อความสองภาษาเขียนแบบ `"ภาษามลายู||ภาษาไทย"` (คั่นด้วยเครื่องหมาย `||`)
หลังแก้แล้วให้รันคำสั่งนี้ในโฟลเดอร์หลักของ repo เพื่อสร้างหน้าเว็บใหม่ (ต้องติดตั้ง Node.js ก่อน)

```
node _src/build.js
```

ถ้าแก้คำผิดเล็กน้อย จะแก้ในไฟล์ `.html` บนหน้า GitHub โดยตรงก็ได้ แต่ถ้ารัน `build.js` ภายหลัง ส่วนที่แก้ใน `.html` จะถูกเขียนทับ

## ไฟล์ PDF ของแต่ละบท

สร้างจากหน้าเว็บบทเรียน (ขนาด A4 ไม่มีเฉลย แบบทดสอบ และบัตรคำ) เมื่อแก้เนื้อหาแล้วต้องสร้าง PDF ใหม่ด้วย

```
node _src/build.js
python3 _src/pdf.py
```

(ต้องติดตั้ง Python และ `pip install playwright` แล้ว `playwright install chromium` ก่อน)
